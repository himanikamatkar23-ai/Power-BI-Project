# Employee Analytics Dashboard | Power BI

## 📌 Project Overview

The **Employee Analytics Dashboard** is a Power BI project developed to analyze employee data and present important workforce insights through interactive visualizations and Key Performance Indicators (KPIs).

The project focuses on employee demographics, department-wise analysis, salary distribution, hiring trends, employee resignations, and performance scores. It helps users understand workforce information and supports data-driven decision-making.

## 🎯 Project Objectives

- Analyze overall employee information.
- Monitor total and active employees.
- Track employee hiring and resignation trends.
- Analyze salary distribution across departments and job titles.
- Evaluate employee performance scores.
- Present important HR metrics through dashboards and KPI cards.
- Make employee data easier to understand through visual reports.

## 🛠️ Tools and Technologies

- **Microsoft Power BI Desktop** – Dashboard development and data visualization
- **Power Query** – Data preparation and transformation
- **DAX (Data Analysis Expressions)** – Calculated measures and KPIs
- **Data Visualization** – Charts, graphs, and KPI cards
- **Microsoft Excel / Structured Data** – Data source, if applicable to the original dataset

## 📊 Dashboard Pages

### 1. Home Dashboard
Provides an overview of important employee metrics.

Key metrics include:
- Total Employees
- Active Employees
- New Hires
- Total Salary
- Employee hiring trends
- Department-wise employee information

### 2. Employee Overview Dashboard
Presents additional employee KPIs and workforce trends.

Key metrics include:
- Average Salary
- Total Salary
- Resigned Employees
- Monthly and yearly hiring trends
- Employee age groups
- Employee promotion information

### 3. Department Analysis Dashboard
Focuses on employee distribution and workforce changes across departments.

Key analysis areas include:
- Department-wise employee count
- Department-wise resignations
- Active employees by department
- New hires by department
- Job title analysis

### 4. Salary Analysis Dashboard
Provides insights into employee compensation.

Key analysis areas include:
- Average Salary
- Highest Salary
- Lowest Salary
- Total Salary
- Salary distribution by department
- Salary range analysis
- Salary analysis by job title and age group

### 5. Performance Analysis Dashboard
Focuses on employee performance and promotion-related information.

Key analysis areas include:
- Average Performance Score
- Highest Performance Score
- Total Performance Score
- Department-wise performance analysis
- Hiring trends and promotion analysis

*Note: The dashboard descriptions summarize the fields and measures identified in the Power BI report. Refer to the actual report for the exact visuals and displayed metrics.*

## 🚀 How to Use This Project

1. Download or clone this repository from GitHub.
2. Install Microsoft Power BI Desktop.
3. Open the `.pbix` file in Power BI Desktop.
4. If Power BI requests access to the original data source, update the data source path or credentials as required.
5. Refresh the data if the original source is available.
6. Navigate through the dashboard pages to explore employee, department, salary, and performance analysis.


## 💡 Project Outcome

This project demonstrates how Power BI can be used to transform employee data into meaningful visual reports. It brings together important workforce indicators in one report and helps users explore employee distribution, compensation, hiring, resignations, and performance.
